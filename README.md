# 朝会議事録当番決め

毎週の朝会における議事録担当者のローテーションを自動で決め、管理するためのWebアプリです。

公開URL: https://asakai-touban.pages.dev
（Basic認証がかかっています。ユーザー名・パスワードは管理者にご確認ください）

## 何のアプリか

チームで持ち回りにしている「朝会の議事録担当」を、手作業の名簿管理なしで決められるようにするツールです。

- 毎週月曜日（祝日の場合は自動で翌日）に、担当者を順番に自動で割り当てます
- 日本の祝日（振替休日・国民の休日を含む）を自動計算し、月曜が祝日なら実施日を翌日にずらします
- お盆・GW・年末年始などの「朝会自体をお休みにする期間」を登録でき、登録すると以降の担当日程が自動で後ろ倒しになります
- 決定済みのスケジュールは、ドラッグ＆ドロップやプルダウンで担当者を入れ替えられます
- スケジュールをGoogle Chatに貼り付けやすいテキスト形式でコピーできます
- 設定・スケジュールをファイルに書き出し／読み込みでき、他のPCへ引き継げます

データはブラウザ内（localStorage）にのみ保存され、外部のサーバーには送信されません。

## 使い方

1. 公開URLを開き、Basic認証のユーザー名・パスワードを入力する
2. 「担当者一覧」で、実際のメンバーの氏名・メールアドレスを登録する（初期状態はサンプルの架空データです）
3. 「スケジュール設定」で、
   - 起点日（すでに決定済みの最後の日）
   - 開始担当者（起点日の次に担当する人）
   - 生成する週数
   を指定し、「スケジュールを生成／再生成」を押す
4. 必要に応じて「朝会中止設定」でお盆・年末年始などの期間を登録する（登録すると以降の日程が自動で調整されます）
5. 「朝会議事録当番スケジュール」の表で、担当者をドラッグ＆ドロップやプルダウンで入れ替えられる。急な欠席時は「この回を中止」から、後ろ倒しするかどうかを選んで対応できる
6. 「Google Chat用テキストをコピー」で、そのままチャットに貼り付けられる形式のテキストをコピーできる
7. 設定を別の担当者や別のPCに引き継ぎたい場合は、「今の設定をファイルに保存」→相手先で「ファイルから設定を読み込む」

## どのようにAIに依頼したか

Claude Code（Anthropicの開発支援AI）と対話しながら、次のような流れで作成しました。

1. **要件を1つのメッセージでまとめて依頼**
   最初に「朝会議事録当番決めを作りたい。1ファイルのHTMLで完結、毎週月曜に担当を割り当てる、起点日を指定できる、祝日は翌日にずらす、中止期間を設定できる、決定後はドラッグ＆ドロップで入れ替えられる、中止日を後から設定したら以降の担当を先送りする、担当者一覧にはメールアドレスも持たせる」という仕様をまとめて伝え、たたき台を一度に作ってもらいました。
2. **実際に触りながら、細かい要望を1つずつ追加**
   完成したものを実際に操作し、「担当者を削除するとき前倒しするか選びたい」「中止にした回を消さずに一覧に残したい」「Google Chatにそのまま貼れる形式が欲しい」など、使ってみて気づいた要望をそのつど伝えて改善してもらいました。
3. **公開に向けた技術的な相談**
   「Cloudflare Pagesで公開したい」と伝えたところ、Cloudflareの管理画面の実際のスクリーンショットを見せながら、1画面ずつ操作方法を教えてもらう形で、GitHub連携・Basic認証・環境変数の設定まで進めました。
   途中、会社の指示（「Cloudflare Pages Functionsの`_middleware`で実装」）に沿えていないことに気づき、その旨を伝えたところ、既存の公開ページを壊さないよう配慮しながら、指定された実装方式に作り替えてもらいました。
4. **スマホでの見え方など、実機で確認しながら調整**
   スマホで見たときに文字が見切れる・ボタンが縦に潰れるといった不具合をスクリーンショットで共有し、原因の説明を受けながら1つずつ直してもらいました。
5. **仕上げの見た目調整**
   ヘッダーのデザインや、よく見るスケジュール表を目立たせたい、といった細かい見た目の好みも、その都度伝えて調整してもらいました。

全体を通して、最初にまとまった仕様を渡した後は、「動くものを見る→気づいた点を伝える→直してもらう」を繰り返す形で、少しずつ完成に近づけていきました。
